## Lógica de programación recomendada

Para cada pantalla:

Perfil del paciente

Objeción del paciente

Seleccione la respuesta del HCP

Opción A

Opción B

Opción C

Resultado inmediato

Si A o B: “Respuesta adecuada” + breve explicación

Si C: “Respuesta no óptima” + por qué no + mejores opciones

CTA final

“Continúe la conversación y evalúe si GARDASIL®9 es una opción adecuada para este paciente.”


## Mensaje final estándar para todas las rutas

“La vacunación contra VPH debe evaluarse de acuerdo con edad, antecedentes, historial de vacunación y criterio médico. Consulte la información aprobada de GARDASIL®9 y confirme el esquema correspondiente según la indicación local vigente.”

## Estructura funcional del interactivo

El contenido fuente puede implementarse como un flujo repetitivo:

```text
Selección de caso
    ↓
Perfil del paciente
    ↓
Objeción
    ↓
Seleccionar respuesta A / B / C
    ↓
Feedback inmediato
    ↓
Siguiente objeción
    ↓
Resultado / CTA final
```

### Regla de evaluación

- **A o B:** mostrar “Respuesta adecuada” + breve explicación.
- **C:** mostrar “Respuesta no óptima” + explicación + mejores opciones A/B.

### Nota

El contenido, las respuestas y el feedback anteriores se mantienen conforme al documento fuente. La estructura funcional se presenta únicamente para facilitar su conversión a un prototipo interactivo.
